# 実プレイテスト計画（知り合いクローズドテスト）

2026-11-26 作成。目的：人間同士で初めて1試合を完走させ、実DB＋Realtime の
未検証部分をまとめて潰す。ストア手続きは一切不要（現行の PWA URL で足りる）。

## 参加条件
- 人数：最低4人（ルームの最小人数）。5〜6人が理想
- 各自：スマホ＋Google アカウント（ログインに使う）
- URL を開いて「Googleでログイン」→ 初回だけ名前と生年月日を入力
  （生年月日は変更不可。年齢確認と課金上限のため。本人確認はなし）

## 当日の流れ（目安30〜45分）
1. 全員ログインしてロビーに入る
2. おぎがルームを作成（公開・4〜6人）
3. 全員が入室 → 準備OK → マスターがゲームスタート
4. 話し合い（チャット）→ 投票 →（ウルフ追放なら逆転回答）→ 結果画面
5. 結果画面から誰かにギフトを送ってみる
6. 2試合目：1人だけ「何も発言せず・投票もしない」放置役をやってみる
   → 警告→強制退室→ペナルティDM まで確認
7. 終了後、DM（個人チャット）を1往復送り合う

## 確認観点（むぜたん側チェックリスト）
- [ ] 試合が例外なく完走する（話し合い→投票→結果→待機室へ戻る）
- [ ] DM がリアルタイムで届く（Realtime の実地確認はこれが初）
- [ ] ギフト到着のスライド通知が相手に出る／人気度が増える
- [ ] 放置ペナルティ：警告→退室→システムDM の順で届く
- [ ] 結果画面の表示（バナー・紙吹雪・集計中）が全員で一致する
- [ ] 誰かの画面で表示崩れ・固まる・戻れない等がないか
